# ninjatech-agent/test-repo

This repository contains simple example scripts that demonstrate how to print "Hello, World!" in various programming languages. These scripts are intended as basic references for beginners and as a demonstration of minimal program structure in each language.

## Examples Directory

All example scripts are located in the `examples` directory. Each script is thoroughly commented to explain the components of the code.

### Available Scripts

#### 1. C

- **File:** `examples/hello_world.c`
- **How to run:**
  1. Compile the program:
     ```
     gcc examples/hello_world.c -o examples/hello_world
     ```
  2. Run the compiled program:
     ```
     ./examples/hello_world
     ```

#### 2. Python

- **File:** `examples/hello_world.py`
- **How to run:**
  ```
  python3 examples/hello_world.py
  ```

#### 3. JavaScript

- **File:** `examples/hello_world.js`
- **How to run (Node.js required):**
  ```
  node examples/hello_world.js
  ```

---

Each script is commented to help you understand the structure and function of a basic "Hello, World!" program in its respective language.
